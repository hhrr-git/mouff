권한 정책

이미 만든 권한그룹(Role)에 “누가 신청할 수 있는지”를 연결합니다. 조직은 조직도, 직무는 조직·인사 체계 데이터를 그대로 불러옵니다.

정책 저장 시 조직명/직무명이 아니라 내부 ID를 연결합니다. 조직명이 바뀌어도 연결은 유지되고, 신청·승인이 끝난 뒤 권한 활성화 직전에도 이 자격조건을 다시 검사하는 구조입니다.

권한 부여

직원의 최종권한을 확인해요. 기본권한 + 조직/직책권한 + 승인받은 업무권한 + 직접부여권한을 합산하고 Scope와 유효기간을 적용합니다.

직급이 높다고 급여권한이 자동으로 생기지 않아요. 조직상 결재권과 업무 데이터 접근권한은 분리합니다.
직원을 조회하면 기본권한 / 조직권한 / 업무권한 / 직접부여권한 / Scope를 한 화면에서 확인하게 됩니다.
